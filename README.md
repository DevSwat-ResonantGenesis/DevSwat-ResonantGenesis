## ⚡ Gateway Middleware & RARA Governance

### Gateway 6-Layer Middleware Stack
Every request processed by `RG_Gateway` passes through six mandatory security layers:
1. `AuthMiddleware`: Validates JWT/OAuth session tokens; injects user context (`user_id`, `org_id`, `role`).
2. `TenantIsolationMiddleware`: Enforces organizational boundaries, strips unverified client tenant headers, applies 600 RPM/org rate limits.
3. `RateLimitMiddleware`: Prevents IP-based denial-of-service (DoS) attacks.
4. `EconomicEnforcementMiddleware`: Validates subscription tier and checks credit balance before processing.
5. `CreditDeductionMiddleware`: Performs path-based credit checks (e.g., Chat: 500, Agent Execution: 2600, Workflow: 4000 credits).
6. `FeatureGateMiddleware`: Enforces plan-level access controls for advanced features (e.g., Code Execution, Blockchain, Hash Sphere).

### RARA (Resident Autonomous Runtime Agent)
Internal platform governance service (`RG_Internal_Invarients_SIM`) that evaluates 3 classes of invariants prior to executing state mutations:
- **Structural**: Ensures file system integrity, dependency tree reachability, and schema validity.
- **Semantic**: Validates execution intent coherence, rationale quality, and confidence scores ($>0.6$).
- **Temporal**: Verifies timing constraints, rate limits, and blast radius thresholds ($\le 2$ services).
